# 雅楽シミュレーター「越天楽」

16人の3D雅楽隊（三管両絃三鼓）で越天楽を合奏し、いま誰が演奏しているかを光で示しながら、楽器を足したり引いたりしながら雅楽のしくみ（三管両絃三鼓・合竹・早四拍子・AABBCCAAB＋留の形式・音頭と留手）を体験できるWebアプリです。

- `index.html` 1枚で動きます（音はすべてWeb Audioで合成）
- 「参加」ボタンから楽器をひとつ選ぶと、その楽器を自分で演奏して合奏に加われます
- 笙の合竹の構成音・曲の形式・編成と座り方・楽器の加わる順番は資料にもとづきます
- 3D表示は Three.js（r128）を使用
- 篳篥・龍笛・笙・琵琶・箏・打物の音は、越天楽のMIDIデータから取り込んでいます（形式 A A B B C C A A B ＋留手。テンポの変化と音の高さは実演の録音に合わせています）
